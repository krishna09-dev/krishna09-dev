## About

<img align="right" width="330" src="https://media.giphy.com/media/13HgwGsXF0aiGY/giphy.gif" />

I work across **UI/UX design, frontend development, and backend systems**.

My design side focuses on product flow, wireframes, prototypes, responsive layouts, reusable UI components, and user-friendly interfaces.

My development side focuses on React, TypeScript, Node.js, FastAPI, ASP.NET Core, REST APIs, authentication, dashboards, CRUD flows, and database-driven applications.

I like building products that feel simple for users and stay structured behind the scenes.
