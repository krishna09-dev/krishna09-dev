## 👨‍💻 About Me

I am a Full-Stack Product Engineer with hands-on experience in React, TypeScript, Node.js, FastAPI, ASP.NET Core, and UI/UX design.

I enjoy building responsive, user-friendly, and practical digital products that connect clean interfaces with reliable backend systems. My work includes frontend development, backend API development, CRUD workflows, authentication, database-driven applications, API integration, dashboard interfaces, and modular system architecture.

Alongside development, I also work with Figma and Canva to create wireframes, prototypes, reusable UI components, and responsive layouts. My design background helps me think about product flow, usability, layout, and user pain points, while my development skills help me turn those ideas into working applications.

I have worked on projects such as OpenCollab, role-based quiz platforms, todo applications, CMS dashboards, automotive workshop management systems, and macOS experiments like Omi-Island. These projects helped me strengthen my skills in REST APIs, protected routing, admin dashboards, database workflows, reusable components, and responsive application design.

Through my internship and trainee experiences at Avenir Tech and ZStudioo, I worked on UI/UX design, frontend features, backend APIs, CRUD flow integration, product design sprints, wireframing, prototyping, and developer handoff.

---

## 🎯 My Approach

I like working at the intersection of design and development.

Design helps me understand the user, simplify the flow, and improve the experience.  
Development helps me turn those ideas into real, working products.

For me, a good product is not only about features. It is also about how easily people can understand, navigate, and use those features.
